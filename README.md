# きらめけ！NEO 〜トップアイドルへの道〜

バーチャルアイドル「NEO」を応援して、研究生からトップアイドルに育てるパズルゲームです。

## 遊び方
- 同じ種類のぷちファンを3つ以上なぞってつなげると消えます（ななめもOK）。
- 5つなぎでペンライト（縦横一列を消す）、7つなぎでスター（同じ種類をぜんぶ消す）ができます。
- ダンボールはとなりで消すと壊れます（テープ付きは2回）。
- 各ステージのミッションを手数内に達成するとクリア。全9ステージで、クリアするたびにNEOの衣装が成長します。

## 動かし方
`index.html` をブラウザで開くだけで遊べます（1ファイルで完結）。
GitHub Pages を有効にすると、スマホからURLで遊べます。
